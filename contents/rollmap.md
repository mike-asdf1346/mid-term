## `二、深入 Linux（現在～大一寒）`

安裝 Linux distros & 實際操作理解底層系統的運作方式，並培養獨立排除問題的能力。
以下是我認為我現階段應該加強跟學習的目標

### Ubuntu（現在～大一寒）
學習目的：
- 熟悉 shell 指令
- 遇到系統問題多去看 System Logs（例如 journalctl、syslog）
- 加強系統管理與問題排除能力

### Arch（大一寒～大一下）
裝 Arch 蠻有趣的，可以學到蠻多像是有關 Linux 系統是怎麼建構的。   
學習目的：
- 理解 Linux 發行版與系統組成
- Arch Linux 安裝及基本設定
- 透過安裝 Arch Linux 學習作業系統的組成（不包含 Arch install)
- 學習錯誤排除及查找官方文件（如官方網站：[archlinux.org](https://archlinux.org/)）

### OverTheWire（Bandit）（大一下）
這個是用來練習一些基礎 Linux 指令的網站，包括怎麼使用 ssh 連線、nc、改變權限 chmod 等等。
學習目的：
- 透過 Bandit 練習指令與 Linux 系統是怎麼運作的
- 等完成全部關卡後，並總結每關用到的指令與觀念
