## `一、程式設計（Current～大一寒）`

現階段優先加強程式設計基礎，尤其是從零開始分析問題、規劃程式架構及獨立完成專案的能力。

### Python 小專案（Current～大一暑）

- 加深 Python 基礎語法與資料型態
- 深入理解物件導向程式設計（OOP）
- 熟悉基礎語法像是：dict、list、function、Class、Object
- 學習 Exception Handling

小實作：利用 Python OOP 建立基本帳戶管理系統

- 建立 Account 與 Customer Class
- 實作帳戶建立與管理
- 實作存款、提款及餘額查詢
- 建立交易紀錄

### 加強程式基礎（大一暑）

- 回頭補強前面不熟的語法與觀念
- 再做一個不同類型的小專案，加強自己獨立規劃與實作的能力

## `三、深入 Linux（Current～大一寒）`

透過 Linux 理解作業系統的運作方式，並培養獨立排除問題的能力。
以下是我認為應該加強 & 學習的目標：

### Ubuntu
學習方向：
- 加強 bash 語法
- 遇到問題多去檢查 System Logs（例如 journalctl、syslog）
- 加強系統管理與問題排除能力

### Arch（有餘力再搞到實體機上，目前裝在 VM 上就可）
學習方向：
- 理解 Linux 發行版與系統組成
- Arch Linux 安裝及基本設定
- 透過安裝 Arch Linux 學習作業系統的組成（不包含 Arch install)
- 學習錯誤排除及查找官方文件（如官方網站：[Archlinux]([archlinux.org](https://archlinux.org/))）

### OverTheWire（Bandit）
學習目的：
- 透過 Bandit 練習 bash 指令與 Linux 系統是怎麼運作的
- 完成全部關卡，並總結每關用到的指令與觀念

---

## `四、網路基礎（大一下~大二上）`

建立完整的網路基礎，理解不同網路協定如何運作，以及資料如何在不同設備之間傳輸。   

### 目標學習：

- 三向交握（Three-Way Handshake：SYN、SYN + ACK、ACK）
- Port 與常見網路服務
- 各式網路協定
- Firewall 基本概念
