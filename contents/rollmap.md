## 一、程式設計（大一上～寒假、大一暑假）

現階段優先加強程式設計基礎，尤其是從零開始分析問題、規劃程式架構及獨立完成專案的能力。

### Python 小專案（大一上～寒假）

- 加深 Python 基礎語法與資料型態
- 深入理解物件導向程式設計（OOP）
- 熟悉基礎語法像是：dict、list、function、Class、Object
- 學習 Exception Handling

小實作：利用 Python OOP 建立基本帳戶管理系統

- 建立 Account 與 Customer Class
- 實作帳戶建立與管理
- 實作存款、提款及餘額查詢
- 建立交易紀錄
- 處理錯誤輸入與例外狀況
- 完成後放上 GitHub 並附上 README

### 加強程式基礎（大一暑假）

- 回頭補強前面不熟的語法與觀念
- 再做一個不同類型的小專案，加強自己獨立規劃與實作的能力

## 三、探索 Linux（大一上～寒假，Bandit 於大一下）

透過實際使用 Linux，理解作業系統的運作方式，並培養獨立排除問題的能力。

### Ubuntu

- 熟悉 bash 語法
- 理解 File Permissions
- 學習 Process Management
- 學會查看 System Logs（例如 journalctl、syslog）
- 加強系統管理與故障排除能力

### Arch（有餘力再於虛擬機中嘗試）

- 理解 Linux 發行版與系統組成
- 熟悉 Arch Linux 安裝及基本設定
- 理解 Package Manager 與套件管理
- 學習閱讀錯誤訊息及查找技術文件
- 理解自己安裝的套件與系統服務

### OverTheWire（Bandit）（大一下完成）

- 透過 Bandit 練習指令與檔案操作
- 完成全部關卡，並記錄每關用到的指令與觀念

## 四、網路基礎（大一下起，大二上持續精進）

建立完整的網路基礎，理解不同網路協定如何運作，以及資料如何在不同設備之間傳輸。可搭配課程：企業資料通訊（大一下）、網路程式設計（大二下）。

### 學習

- 理解三向交握（Three-Way Handshake：SYN、SYN + ACK、ACK）
- Port 與常見網路服務
- 各式網路協定
- Firewall 基本概念

### 練習

- 使用 Wireshark 擷取測試環境中的網路流量
- 分析 TCP 三向交握
- 觀察 DNS 查詢流程
- 整理封包分析紀錄

## 五、CTF 與 Writeups（大一暑假接觸，大二下整理 Writeup）

在具備基礎後，逐步接觸資訊安全領域，透過合法授權的實驗環境與 CTF 練習實際技術。入門先從對初學者友善的 picoCTF 開始。

- 題目背景與目標
